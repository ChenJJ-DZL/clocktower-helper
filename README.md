## 🎭 核心亮点与系统特性

### 🧠 1. 深层语义与拟真逻辑引擎
- **全量 200+ 角色支持**：新引擎能力注册库覆盖 **214 个角色能力**，镇民 / 外来者 / 爪牙 / 恶魔 / 旅行者 / 寓言角色全量纳入，每个角色均有独立的语义管道（Setup / Night / Day / Passive）。
- **疯子 (Lunatic) 完整假恶魔模拟**：独立生成虚假爪牙认知、虚假夜间击杀名单流转与时序，与真实恶魔杀人链物理隔离。
- **提线木偶 (Marionette) 六来源防泄漏**：告密者、传教士、小怪宝、罂粟种植者、帽匠、落难少女等全链路伪装假值与屏蔽，确保木偶玩家绝不通过信息破绽察觉真实身份。
- **洗脑师 (Cerenovus) 专属疯狂链路**：专属确认页与「被洗脑告知」时序节点，作为座位右上角标记栈「疯狂:X」呈现。
- **全局防窥脱敏机制 (Global Privacy Shield)**：支持说书人将设备递给玩家时的「零泄漏」玩家视角，长按 1 秒解锁说书人完整视图，彻底杜绝窥屏。
- **受干扰信息与真值同形机制**：酒鬼、中毒、涡流等状态下的信息生成，自动产出与真值同等格式的合法假信息，杜绝机械破绽。
- **高阶能力深度联动**：弄蛇人阵营与角色互换、筑梦师双候选、哈迪哈生死抉择、卡扎丽爪牙转化、涡流全信息必假、军团全员投票与结算、镜像双子存活终局锁定。

### 🌙 2. 自动化夜晚拓扑流转
- **动态唤醒队列**：依据当前剧本角色、存活状态及状态传播，精准编排首夜与后续夜晚流转队列。
- **首夜系统流程**：恶魔爪牙互认、伪装身份发放、指定提示全流程引导。
- **状态传播与生命周期**：醉酒、中毒跨日递减与自动过期（如侍臣 3 天倒计时、黎明/黄昏标记清空）。
- **智能一键建议**：自动化候选人推荐与规则校验，大幅降低说书人控场心智负担。

### ☀️ 3. 白昼讨论与黄昏提名计票系统
- **讨论计时器**：中央罗盘荧光呼吸倒计时动效，支持自由设定与暂停。
- **官方黄昏提名控制**：严格对齐官方规则（同一黄昏内每名玩家限发起 1 次提名，且每个座位限被提名 1 次）。
- **阶梯处决投票**：支持幽灵票（死者票）消耗追踪、官职威能（专制总监/代理人）直接处决裁决。
- **官方终局规则裁决**：圣徒处决即负、市长和平获胜与替死、军团人数阈值判定等官方规则判定。

### 🏷️ 4. 说书人标记体系与移动端触屏打磨
- **官方规格标记体系**：预设 11+ 种标准标记（受保护、中毒、醉酒、死亡标记、假身份、是恶魔、是爪牙、已用能力等）及自定义标记。
- **右上角标记栈排布**：真实身份提示（「实:X」）、疯狂标记（「疯狂:X」）、双子标记、图书目标等同行居中排布，底部状态胶囊紧凑收敛。
- **移动端触屏深度适配**：5 字角色名智能 3+2 折行排版，长按 1 秒即时弹出座位右键菜单，拖动浮层 1.1x 真实渲染，屏蔽移动端原生手势与下拉刷新干扰。

### ⏳ 5. 时光倒流 Undo/Redo & 快照持久化
- **原子动作级撤销与重做**：夜晚单次行动、白天投票计票、提醒标记增删均可独立精准回退。
- **本地快照实时持久化**：网页意外刷新或关闭后，一键无损恢复当前对局上下文与历史日志。

### 📊 6. 高清复盘长图导出 & 对局回放
- **一键高清长图**：基于 html2canvas 高清导出对局复盘图片，适配移动端与桌面端分享。
- **对局记录归档**：完整记录每夜刀口、技能施放与白天处决历史，复盘分析一目了然。

## 🎨 双主题系统架构

魔典 UI 原生支持**双主题架构**——同一套状态机与底层交互逻辑，两套高质感视觉语言，顶栏胶囊一键无刷新热切换：

- **✨ 现代 (Modern) — 暗黑哥特拟物风（默认主题）**
  - 深邃暗夜黑曜石暗角渐变背景，磨砂玻璃悬浮顶栏
  - 拟物圆桌代币：金属边缘高光 + 立体内阴影，按阵营散发微光（镇民圣堂金 / 外来者幽光翡翠 / 爪牙焦木琥珀 / 恶魔猩红魔火）
  - 死亡玩家覆盖干裂纹理与血色印记
  - 中央复古法阵罗盘环绕阶段/计时器，倒计时荧光呼吸动效
  - 渐进式信息精简：角色说明折叠为极简手风琴（📖 查看完整规则 Wiki），主操作按钮流光渐变边框
  - 悬浮注解系统：Hover / 点击任意代币弹出深色羊皮纸卡片（角色全称 / 阵营 / 一句话能力 / 当前状态标记）
- **🏛️ 经典 (Classic) — 高对比扁平风完整回退**
  - 纯色深蓝底、扁平实心代币，右侧说明默认平铺展开，老玩家零迁移成本

> 主题偏好持久化于 `localStorage`；基于 Tailwind CSS 4 `@custom-variant` 作用域样式隔离，确保双主题切换不发生状态漂移。

## 🚀 本地开发指南

### 环境准备

确保本机已安装 Node.js (推荐 v20+) 与 npm。

```bash
# 克隆仓库
git clone https://github.com/chenj/clocktower-helper.git
cd clocktower-helper

# 安装依赖
npm install
```

### 开发与构建指令

```bash
# 启动本地开发服务器 (默认端口 3000)
npm run dev

# 执行 Vitest 单元与集成测试套件 (4,100+ tests)
npm run test

# 执行 Playwright 真实浏览器端到端测试 (96 E2E tests)
npm run test:e2e

# 运行全链路代码门禁 (格式化/Lint/类型检查/测试/循环依赖检测)
npm run check

# 生产环境打包构建 (Next.js standalone)
npm run build
```
